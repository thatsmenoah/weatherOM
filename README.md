# Weather Cloud

Мобильное приложение погоды на Flutter для Android.

## Возможности

- Текущая погода, почасовой прогноз и прогноз на 7 дней: температура, ветер,
   влажность, давление и вероятность осадков.
- Время рассвета и заката, качество воздуха и дополнительные погодные показатели.
- Автоматическое определение местоположения и поиск городов.
- Избранные и недавно выбранные места сохраняются на устройстве.
- Советы по погоде, обновление жестом и встряхиванием телефона.
- Локальный кеш погоды для быстрого показа при повторном запуске и работы без сети.
- Русский и английский интерфейс; настройки показывают версию, changelog и размер
   данных, кеш можно очистить.
- Анонимная авторизация Firebase и проверка обновлений через Firestore.
- Загрузка APK из GitHub Releases и запуск системного установщика Android.

## Данные и хранение

- Open-Meteo предоставляет прогноз, качество воздуха и результаты поиска городов.
- OpenCage используется для обратного геокодирования. Без API-ключа приложение
   показывает координаты вместо адреса.
- Погода и прогноз кешируются в JSON-файле приложения; язык, избранное и история
   поиска хранятся локально.
- Firebase Auth создаёт анонимный идентификатор установки. Firestore хранит только
   конфигурацию доступной версии; правила находятся в `firestore.rules`.

## Запуск

Нужен Flutter SDK, подходящий под ограничение в `pubspec.yaml`.

```powershell
flutter pub get
```

Создайте `.env` в корне проекта и задайте ключ OpenCage:

```dotenv
OPENCAGE_API_KEY=ваш_ключ
```

Ключ необязателен: без него адрес заменяется координатами. Затем запустите:

```powershell
flutter run
```

## Релиз Android

GitHub Actions собирает подписанный APK, создаёт GitHub Release и обновляет
Firestore при push нового тега `v*`. Сначала поднимите `version` в `pubspec.yaml`
и отправьте коммит в `main`, затем создайте уникальный тег. Например, для версии
`1.1.1-r+10`:

```powershell
git tag v1.1.1r-build10
git push origin v1.1.1r-build10
```

Тег `v1.1.1r` уже использовался, поэтому повторно применять его нельзя. APK
публикуется как `weather-cloud-1.1.1r.apk`; после завершения workflow приложение
предложит его пользователям с более старым `versionCode`.
