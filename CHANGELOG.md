# Changelog

Все значимые изменения этого проекта документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
а версия соответствует [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.3r] — 2026-10-06

### ⚡ Улучшения архитектуры
- **Зависимости внедрены явно.** `WeatherNormalizer` больше не создаёт `LocaleManager` внутри — язык передаётся через параметр. Нормализатор стал чистым, тестируемым компонентом без скрытого глобального состояния.
- **UI-компоненты вынесены из `core/`.** `StatusToast`, `LoadingErrorWidget`, `UpdateTimeIndicator` и `NoGlowBehavior` переехали в `widgets/loading_widgets.dart`. Core-слой теперь содержит только бизнес-логику.
- **Утилиты мапирования объединены.** Дублирующийся `_asMap` заменён на общий `map_utils.dart`.

### 🧪 Тестирование
- Добавлены unit-тесты для `WeatherNormalizer` (числа, массивы с `null`, fallback, точка росы, AQI, солнце, доп. метрики).
- Добавлены тесты для `DataSystem` (схема, битый кеш, очистка, пустые данные).
- Все тесты стабильно проходят (55/55).

### 🐛 Исправления
- Race-condition защита запросов (`requestId`) сохранена и проверена тестами.
- Graceful fallback GPS (GPS → last known → low accuracy) работает стабильно при холодном старте.

### 📦 Релиз
- Версия: `1.1.3r+1`
